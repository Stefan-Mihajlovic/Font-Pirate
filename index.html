About font previews

Type Pilot reads CSS font families. Previews use fonts available on this device, so website fonts may fall back. Exports retain the original values.

Using the inspector

Pick a font, then click text. Press Esc to cancel. Browser pages, PDFs and embedded frames are not supported.

Storage and backups

Pairings stay on this device. Back up your library before removing the extension. Up to 200 pairings.
